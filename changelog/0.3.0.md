The first release of `@glass-hq/documents`: Glass's document viewer and Markdown converter for the browser, built on Firecrawl's anydoc parser compiled to WebAssembly.

### New

- `toMarkdown` turns PDF, Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV and TSV into GitHub-Flavored Markdown. Markdown and text pass through as written, and images, video, audio and fonts become a line describing the file. It takes a `File`, `Blob`, bytes, URL or stream, and runs on a worker.

  ```js
  import { toMarkdown } from "@glass-hq/documents";

  const markdown = await toMarkdown(file);
  ```

- `toDocument` stops at the document model, with embedded images as bytes, and `toWorkbook` reads a spreadsheet with its styles, sizes, panes, links, images, charts, tables, conditional formats and list validations resolved into each cell.
- The format is detected from the bytes (`detectFormat`). A name or media type only decides for files without a signature, like CSV or Markdown. One registry of 23 formats (`formats`, `formatFromName`, `formatFromMediaType`) drives detection, byte limits, parsing and rendering.
- `createViewer` renders any of those formats into an element and draws nothing else. Your controls read its state and call its actions for pages, zoom, search, sheets and thumbnails (`renderThumbnail`).

  ```js
  import { createViewer } from "@glass-hq/documents";

  const viewer = createViewer(element, file, { onLink: (url) => window.open(url) });
  viewer.subscribe(() => {
    const { page, zoom, search, sheets } = viewer.getState();
  });
  viewer.search("revenue");
  ```

- PDFs render through pdf.js with a text layer, and search highlights every match. Word renders as pages through docx-preview, PowerPoint as slides through pptx-renderer, and spreadsheets as a grid with their styles, merges, charts, data bars, dropdowns and filter buttons. The other document formats render as a reading view built from the document model. Word lists are numbered as Word counts them, and Symbol, Wingdings and StarBats bullets map to Unicode.
- `@glass-hq/documents/react` has `useDocumentViewer` and `<DocumentView>`.
- `@glass-hq/documents/formats` has the format registry and detection alone, with nothing that touches the DOM or loads WebAssembly, for servers and React Native.
- Every file is treated as hostile: nothing in a document runs or loads from the network, and links go through `onLink`. The viewer's styles sit in a `documents` cascade layer, with `--documents-*` custom properties for theming.
- PDF to Markdown loads a second WebAssembly build with the PDF engine only when it's needed, so everything else stays in the smaller build. Scanned pages are reported as `needsOcr`.
